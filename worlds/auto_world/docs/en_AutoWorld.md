# Auto World

Auto World is an automated test environment for Archipelago.

## Features
- **Configurable Locations & Tiers**: Generate anywhere from 5 to 100 locations partitioned across 1 to 5 progression tiers.
- **Progression Logic**: Key items unlock higher tiers, allowing validation of progression logic and item routing.
- **Automated CLI Bots**: Multi-slot bot manager that self-plays rooms, automatically checks reachable locations, collects items, and reports goal completion to the server.
- **Interactive Control**: Adjust intervals on the fly, force location checks, trigger goals, send hints, and simulate deathlinks.
